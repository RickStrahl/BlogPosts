# Back to Basics: File Uploads in ASP.NET

Uploading files with HTML and HTTP remains one of the most annoying things in the HTML and HTTP spec. HTML has very limited support for file uploads, and provides only the incredibly inflexible File Upload control using `<input type="file" />` which is both incredibly limited in terms of features and impossible to style consistently across browsers. As a result there are all sorts of work arounds that deal with doing uploads in different ways from using Ajax uploads to complex, components that do 'chunked' uploads to get around Web Server POST size limitations as well as a bunch of hacks that use manually styled HTML to handle the upload UI. In this post I'll discuss basic HTML uploads including the relatively new support for multiple files in a single upload, basic AJAX uploads as well as using plUpload to send chunked uploads to the server using multiple files.

### Basic HTML Uploads
We start by looking at the plain ole' HTML `<input type="file" />` control which has been part of the HTML standard since the very beginning. File uploads essentially allow you to pick a file from disk using your OS file dialog box and then upload that file to the server. The default HTML behavior uses an HTML form using a multipart/mime data encode to embed both the raw file data (in binary form) as well as any form variables into the HTTP request that's sent to the server
